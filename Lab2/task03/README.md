# Задание 3 — Поиск подстроки в нескольких файлах

## Условие

Реализовать функцию с переменным числом аргументов, принимающую
в качестве входных параметров:

- подстроку;
- количество файлов `nfiles`;
- пути к этим файлам (через `...`).

Для каждого файла функция ищет все вхождения подстроки в содержимом.

## Ограничения

- ❌ Запрещено использовать `strstr` и `strncmp` из `string.h`.
- ✅ Свой поиск реализован вручную (наивный алгоритм, O(n·m)).

## Компиляция

	gcc -std=c99 -Wall -Wextra -Wpedantic -o task3 task3.c

Использование:

	./task3 <подстрока> <файл1> [файл2 ...]

Пример:

f1.txt:
hello world hello

f2.txt :
goodbye

	./task3 hello f1.txt f2.txt
Выход:

Поиск подстроки "hello" в 2 файле(ах):
  [1] 'f1.txt': 2 вхождений
  [2] 'f2.txt': 0 вхождений

Ограничения реализации:

Чтение по блокам (fread) → поддержка больших файлов.

Пересечения учитываются (например, "aa" в "aaa" → 2 вхождения).

Максимум 8 файлов в диспетчере (C не позволяет построить va_list
динамически из argv).
