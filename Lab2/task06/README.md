# Задание 6 — `overfscanf` / `overscanf`

## Условие

Реализовать функции `overfscanf` и `overscanf`, поведение которых
совпадает с поведением стандартных `fscanf` и `sscanf`, но с
дополнительными флагами.

## Дополнительные флаги

| Флаг | Аргументы | Описание |
|------|-----------|----------|
| `%Ro` | `int *` | Чтение римского числа |
| `%Zr` | `unsigned int *` | Чтение Zeckendorf |
| `%Cv` | `int *, int(base)` | Чтение base → int (строчные) |
| `%CV` | `int *, int(base)` | Чтение base → int (прописные) |

## Компиляция

	gcc -std=c99 -Wall -Wextra -Wpedantic -o task6 task6.c

Использование:

	./task6

Пример:

int v;
overfscanf(f, "%Ro", &v);        /* Читает MCMXCIV → v = 1994 */
overscanf("ff", "%Cv", &v, 16);  /* → v = 255 */

Ограничения:

Никаких errno, никакого goto, никакого exit() вне main.

const для неизменяемых параметров.

Без проверки входных данных (по условию).

tmpfile() (стандарт C89) для тестов.
