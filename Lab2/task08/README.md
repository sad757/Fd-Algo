# Задание 8 — Сложение больших чисел в произвольной системе

## Условие

Реализовать функцию с переменным числом аргументов, вычисляющую сумму
переданных неотрицательных чисел в заданной системе счисления
с основанием `[2..36]`.

Параметры функции:
- основание системы счисления;
- количество переданных чисел;
- строковые представления чисел.

Десятичное представление может быть слишком велико для встроенных типов,
поэтому реализована функция «сложения в столбик» двух чисел в заданной
системе.

Результат — строка **без ведущих нулей**.

## Компиляция

	gcc -std=c99 -Wall -Wextra -Wpedantic -o task8 task8.c

Использование:

	./task8 <base> <n1> <n2> ... <nk>

Пример:

# Сумма 1A + 2B в base 16
./task8 16 1A 2B
# → 45

# Сумма 10 + 20 + 30 в base 10
./task8 10 10 20 30
# → 60

# Сумма FF + 1 в base 16
./task8 16 FF 1
# → 100

Ограничения:

Никакого errno, никакого goto, никакого exit() вне main.

const для неизменяемых параметров.

Управление памятью (освобождение всех буферов).

Результат без ведущих нулей.

Диспетчер ограничен 8 числами (техника va_list).
