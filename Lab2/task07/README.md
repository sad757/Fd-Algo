# Задание 7 — Поиск векторов с максимальной нормой

## Условие

Реализовать функцию с переменным числом аргументов, на вход которой
подаются:

- размерность пространства `n`;
- экземпляр структуры, содержащей координаты векторов из `n`-мерного
  пространства;
- указатель на функцию, вычисляющую норму векторов.

Для каждой переданной нормы функция возвращает **все** векторы
с наибольшей нормой.

## Нормы

- ‖x‖∞ = max |xⱼ|
- ‖x‖ₚ = (Σ |xⱼ|ᵖ)^(1/p), p ≥ 1 (реализовано для p = 2)
- ‖x‖ₐ = √(Ax,x), где A — положительно определённая матрица

## Компиляция

	gcc -std=c99 -Wall -Wextra -Wpedantic -o task7 task7.c -lm

Использование:

	./task7 <n> <norm_type> <v1_1> ... <v1_n> [<v2_1> ... <v2_n> ...]

n : размерность

norm_type : inf, p2 или A

затем : count × n координат векторов

Пример:
./task7 2 p2 3 4 0 5 1 1


Выход:

Векторов с максимальной нормой: 2
  [1] (3, 4)
  [2] (0, 5)

Ограничения:

Нет errno, нет goto, нет exit() вне main.

const для параметров.

Управление памятью (освобождение всех векторов).

Диспетчер ограничен 3 векторами × 5 измерений (техника va_list).
