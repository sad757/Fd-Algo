# Задание 10 — Переразложение многочлена

## Условие

Реализовать функцию с переменным числом аргументов, находящую
переразложение многочлена со степенями значения `x` по степеням
значения `(x - a)`.

Дано: `f(x) = f0 + f1·x + ... + fn·x^n`.

Найти: `g0, g1, ..., gn` такие, что
`f(x) = g0 + g1·(x-a) + ... + gn·(x-a)^n`.

## Компиляция

	gcc -std=c99 -Wall -Wextra -Wpedantic -o task10 task10.c -lm

Использование:

	./task10 <eps> <a> <n> <f0> <f1> ... <fn>

eps : точность

a : точка разложения

n : степень

f0..fn : коэффициенты (от младшей степени к старшей)

Пример:

# f(x) = x² - 3x + 2, разложить около a=1
	./task10 1e-9 1 2 2 -3 1
# → g = [0, -1, 1]
# → f(x) = 0 - 1·(x-1) + 1·(x-1)²

Метод:

Алгоритм Хорнера повторяется (n+1) раз

На каждом шаге извлекается g_i путем вычисления в a, затем выполняется синтетическое деление на (x - a), чтобы перейти к следующему коэффициенту

Сложность: O(n²)

Ограничения:

Без errno, без goto, без exit() вне main. const на параметры.

Динамическое выделение массива g (освобождается в main).

Диспетчер ограничен n ≤ 8 (техника va_list).
