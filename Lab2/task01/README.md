# Задание 1 — Операции над строками

## Условие

Через аргументы командной строки программе подаются флаг (первым
аргументом), строка (вторым аргументом) и, только для флага `-c`,
целое число типа `unsigned int` и далее произвольное количество строк.

| Флаг | Действие |
|------|----------|
| `-l` | Подсчитать длину строки |
| `-r` | Получить перевёрнутую строку |
| `-u` | Нечётные позиции (начиная с 0) → верхний регистр |
| `-n` | Сначала цифры, потом буквы, потом остальные (в исходном порядке) |
| `-c` | Конкатенация строк в псевдослучайном порядке (seed в 3-м аргументе) |

## Компиляция

	gcc -std=c99 -Wall -Wextra -Wpedantic -o task1 task1.c

Использование:

	./task1 -l "hello"                    # → 5
	./task1 -r "hello"                    # → olleh
	./task1 -u "abcdef"                   # → aBcDeF
	./task1 -n "a1!b2@c3"                 # → 123abc!@
	./task1 -c "ignore" 42 "one" "two" "three"   # → порядок зависит от seed 42

Ограничения:

Функции из string.h не используются в реализациях флагов

Результат выделяется в динамической памяти и освобождается в main

const на входных параметрах

Коды возврата через enum status_t

Без errno, без goto, без exit() вне main
