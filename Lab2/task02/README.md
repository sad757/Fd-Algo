# Задание 2 — Сортировка сотрудников

## Условие

На вход программе через аргументы командной строки подаётся путь к
входному файлу, флаг (`-a` или `-d`) и путь к выходному файлу.
Каждая строка входного файла содержит:

id name surname salary


- `id` — целое неотрицательное число;
- `name` — непустая строка из латинских букв;
- `surname` — непустая строка из латинских букв;
- `salary` — неотрицательное вещественное число.

Программа считывает записи в динамический массив структур `Employee`
и выводит в выходной файл данные, отсортированные:

- с флагом `-a` — по возрастанию;
- с флагом `-d` — по убыванию;

первично по зарплате, далее (если равны) по фамилии, далее по имени,
наконец, по `id`.

## Компиляция

	gcc -std=c99 -Wall -Wextra -Wpedantic -o task2 task2.c

Использование:

	./task2 <входной> -a <выходной>
	./task2 <входной> -d <выходной>

Пример:

in.txt:

1 Alice Smith 3000.0
2 Bob Johnson 5000.0
3 Charlie Smith 5000.0
4 Dave Brown 3000.0
5 Eve Johnson 5000.0

./task2 in.txt -a out.txt → out.txt :

1 Alice Smith 3000.000000
4 Dave Brown 3000.000000
2 Bob Johnson 5000.000000
3 Charlie Smith 5000.000000
5 Eve Johnson 5000.000000

Ограничения:

qsort обязательно (никакой самодельной сортировки)

Без string.h (кроме qsort, которому он не нужен)

Без errno, без goto, без exit() вне main

const на функциях сравнения

Управление памятью (очистка name и surname при каждом выходе)
