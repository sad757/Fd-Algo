# Задание 9 — Дроби в системе счисления с заданным основанием

## Условие

Реализовать функцию с переменным числом аргументов, которая для каждой
из переданных десятичных дробей (`double` в диапазоне `(0; 1)`)
определяет, имеет ли она конечное представление в системе счисления
с заданным основанием.

## Компиляция

	gcc -std=c99 -Wall -Wextra -Wpedantic -o task9 task9.c -lm

Использование:

	./task9 <base> <d1> <d2> ... <dk>

Пример:

./task9 2 0.5 0.25 0.1
# → 0.5  : КОНЕЧНОЕ        (1/2)
#   0.25 : КОНЕЧНОЕ        (1/4)
#   0.1  : бесконечное     (1/10 в base 2 → 0.0001100110011...)

./task9 10 0.5 0.25 0.1
# → 0.5  : КОНЕЧНОЕ
#   0.25 : КОНЕЧНОЕ
#   0.1  : КОНЕЧНОЕ        (0.1 в base 10)

Метод:

Теоретический критерий: p/q (несократимая дробь) имеет конечное представление в системе счисления с основанием b тогда и только тогда, когда q не имеет других простых множителей, кроме тех, что есть у b.

Для double: умножаем число на основание несколько раз и смотрим, станет ли дробная часть 0 (конечная) или начнет повторяться (периодическая).

Ограничения:

Никаких errno, никакого goto, никакого exit() вне main.

const для параметров.

Управление памятью (никакого malloc в check_all).

Диспетчер ограничен до 8 частей (техника va_list).
