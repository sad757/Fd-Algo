# Задание 4 — Резервное копирование (задача о рюкзаке 0/1)

## Условие

На сервере хранится набор файлов. Для каждого файла известны имя,
размер и важность. Нужно выбрать подмножество файлов так, чтобы:

- суммарный размер ≤ вместимость накопителя;
- суммарная важность максимальна;
- каждый файл целиком, не более одного раза.

## Вход (stdin)

n capacity
filename1 size1 importance1
...
filenamen sizen importancen


- `n` — количество файлов (положительное);
- `capacity` — вместимость накопителя (≥ 0);
- `filename` — без пробелов;
- `size` — положительное целое;
- `importance` — целое ≥ 0.

## Выход (stdout)

TOTAL_SIZE S
TOTAL_IMPORTANCE I
FILES k
filename1
...
filenamek


## Компиляция

	gcc -std=c99 -Wall -Wextra -Wpedantic -o task4 task4.c

Пример:

in.txt :
5 10
a 5 10
b 4 40
c 6 30
d 3 50
e 2 30

	./task4 < in.txt

Выход:
TOTAL_SIZE 10
TOTAL_IMPORTANCE 120
FILES 3
b
d
e

Метод:

Динамическое программирование (рюкзак 0/1) с dp[capacity].

Обратный проход через матрицу taken[i][c], чтобы найти выбранные файлы.

Сложность: O(n × capacity) по времени, O(n × capacity) по памяти.

Ограничения:

Нет errno, нет goto, нет exit() вне main.

const для неизменяемых параметров.

Управление памятью (освобождение всех name + files + dp + taken + selected).

Файлы: никаких открытий файлов (чтение из stdin).
