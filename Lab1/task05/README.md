# Задание 5 — Суммы рядов и интегралы

## Условие

### 1. Суммы рядов с точностью ε

- a) Σ_{n=0}^∞ xⁿ / n!
- b) Σ_{n=0}^∞ (−1)ⁿ x²ⁿ / (2n)!
- c) Σ_{n=0}^∞ 3 · 3ⁿ · (n!)³ · x²ⁿ / (3n)!
- d) Σ_{n=1}^∞ (−1)ⁿ (2n−1)!! x²ⁿ / (2n)!!

### 2. Интегралы с точностью ε

- a) ∫₀¹ ln(1+x)/x dx
- b) ∫₀¹ e^(−x²/2) dx
- c) ∫₀¹ ln(1/(1−x)) dx
- d) ∫₀¹ xˣ dx

## Компиляция

	gcc -std=c99 -Wall -Wextra -Wpedantic -o task5 task5.c -lm

Использование

	./task5 -sa 1e-10 1        # e^1
	./task5 -sb 1e-10 1        # cos(1)
	./task5 -sc 1e-10 1
	./task5 -sd 1e-10 0.5
	./task5 -ia 1e-8           # ≈ 0.822467  (π²/12)
	./task5 -ib 1e-8           # ≈ 0.855624
	./task5 -ic 1e-8           # = 1
	./task5 -id 1e-8           # ≈ 0.783430

Метод

Ряды: суммируем, пока |S_{n} − S_{n−1}| ≥ ε.

Интегралы: метод Симпсона с удвоением числа отрезков до достижения
относительной точности ε.

Коды возврата

Код		Значение

ST_OK		успех
ST_ERR_ARGC	неверное число аргументов
ST_ERR_FLAG	неверный флаг
ST_ERR_PARSE	параметр не число
ST_ERR_RANGE	параметр вне диапазона
ST_ERR_CONV	сходимость не достигнута
