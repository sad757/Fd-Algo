# Задание 8 — Восстановление основания системы счисления

## Условие

В текстовом файле находятся числа, записанные в разных системах счисления
(диапазон `[2..36]`), при этом информация о конкретной системе счисления
для каждого числа утеряна. Числа разделены произвольным количеством
разделителей (пробелы, табуляции, переводы строк).

Для каждого числа программа должна:

1. определить **минимальное основание** системы счисления (в диапазоне
   `[2..36]`), в которой представление этого числа корректно;
2. вывести входное число **без ведущих нулей**;
3. вывести определённое для него минимальное основание;
4. вывести представление этого числа в системе счисления с основанием **10**.

Прописные и строчные буквы латинского алфавита отождествляются.

## Компиляция

	gcc -std=c99 -Wall -Wextra -Wpedantic -o task8 task8.c


Использование

	./task8 <входной_файл> <выходной_файл>

Формат вывода

Каждая строка выходного файла:
<нормализованное_число>\t<основание>\t<значение_в_10>

Пример

Входной файл:
1010 ZZZ 12 FF 777 G 0 A
Выходной файл:
1010    2    10
ZZZ     36   46655
12      3    5
FF      16   255
777     8    511
G       17   16
0       2    0
A       11   1
0
Коды возврата

Код			Значение

ST_OK			успех
ST_ERR_ARGC		неверное число аргументов
ST_ERR_OPEN_IN		ошибка открытия входа
ST_ERR_OPEN_OUT		ошибка открытия выхода
ST_ERR_READ		ошибка чтения
ST_ERR_WRITE		ошибка записи
ST_ERR_BAD_CHAR		недопустимый символ
ST_ERR_OVERFLOW		переполнение
