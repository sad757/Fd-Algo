# Задание 10 — Интерактивный ввод, разные системы счисления

## Условие

Пользователь вводит в консоль основание системы счисления (в диапазоне
`[2..36]`) и затем строковые представления целых чисел в этой системе
(цифры со значением больше 9 — прописными буквами латинского алфавита).
Окончанием ввода является ввод строки `Stop`.

Найти среди введённых чисел:

- **максимальное по модулю**;
- **сумму** всех введённых чисел.

Напечатать эти числа **без ведущих нулей**, а также их строковые
представления в системах счисления с основаниями **9, 18, 27 и 36**.

## Компиляция

	gcc -std=c99 -Wall -Wextra -Wpedantic -o task10 task10.c

Использование

	./task10

Пример сессии

Основание [2..36]: 16
Число (или "Stop"): FF
Число (или "Stop"): -1A
Число (или "Stop"): 100
Число (или "Stop"): Stop

Результаты

Количество значений: 3
Сумма: 485
Максимум по модулю: 255

Замечания
Идентификаторы strcasecmp — POSIX. Для MSVC используйте _stricmp
или напишите свою реализацию на tolower.

Сумма проверяется на переполнение long long.

Максимум по модулю вычисляется через unsigned long long, чтобы
избежать UB при -LLONG_MIN.

Коды возврата

Код			Значение

ST_OK			успех
ST_ERR_PARSE		ошибка разбора
ST_ERR_RANGE		значение вне диапазона
ST_ERR_OVERFLOW		переполнение
ST_ERR_NOMEM		недостаточно памяти
ST_ERR_READ		ошибка чтения
ST_ERR_BAD_NUM		недопустимая цифра
ST_ERR_EMPTY		ничего не введено
