## Компиляция

Общий вид:

	gcc -std=c99 -Wall -Wextra -Wpedantic taskNN/taskN.c -o taskN

Для заданий, использующих математические функции (2, 5, 6), добавьте -lm:

	gcc -std=c99 -Wall -Wextra -Wpedantic -lm task02/task2.c -o task2
	gcc -std=c99 -Wall -Wextra -Wpedantic -lm task05/task5.c -o task5
	gcc -std=c99 -Wall -Wextra -Wpedantic -lm task06/task6.c -o task6

Примеры запуска

	./task1 -f 10                 # → 10! = 3628800
	./task2 e 1e-10               # → e
	./task3 -t 1e-9 3 4 5         # → прямоугольный треугольник
	./task4 -d in.txt             # → out_in.txt
	./task5 -ia 1e-8              # → ≈ 0.822467
	./task6 -pow 2 10             # → 1024
	./task7 -r f1.txt f2.txt out.txt
	./task8 in.txt out.txt
	./task9 -1 -50 50
	./task10                       # интерактивно

Соглашения
Язык: C99 (-std=c99 -Wall -Wextra -Wpedantic)

Ошибки: коды возврата через enum status_t, без exit() вне main

Память: проверка всех malloc, освобождение во всех ветках

Файлы: fclose для всех потоков, в том числе при ошибках

Разделение: логика ≠ ввод/вывод

Вещественные числа: сравнение с эпсилон, передаваемым как параметр

const: везде, где модификация не предполагается

Без глобальных переменных
