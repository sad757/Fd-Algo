# Задание 3 — Уравнения, делимость, прямоугольный треугольник

## Условие

Через аргументы командной строки программе подаётся флаг (начинается
с `-` или `/`) и набор чисел. Необходимо проверять соответствие
количества параметров введённому флагу.

## Флаги

- `-q <эпсилон> <a> <b> <c>` — первый параметр задаёт точность сравнения
  вещественных чисел, оставшиеся три — коэффициенты квадратного уравнения.
  Вывести решения для **всех уникальных перестановок** коэффициентов;
- `-m <n1> <n2>` — два ненулевых целых числа. Определить, кратно ли первое
  число второму;
- `-t <эпсилон> <a> <b> <c>` — первый параметр задаёт точность, оставшиеся
  три — потенциальные длины сторон прямоугольного треугольника.

## Компиляция

	gcc -std=c99 -Wall -Wextra -Wpedantic -o task3 task3.c -lm

Использование

	./task3 -q 1e-9 1 -3 2       # x^2 - 3x + 2 = 0 и все перестановки
	./task3 -q 1e-9 1 1 1        # одна перестановка (все равны)
	./task3 -m 15 3              # 15 кратно 3
	./task3 -m 15 4              # 15 не кратно 4
	./task3 -t 1e-9 3 4 5        # прямоугольный треугольник
	./task3 -t 1e-9 3 4 6        # не прямоугольный
	./task3 -t 1e-9 1 2 10       # вообще не треугольник

Пример

	$ ./task3 -t 1e-9 3 4 5
	Прямоугольный треугольник: гипотенуза = 5.0000, катеты = 3.0000 и 4.0000

	$ ./task3 -m 15 3
	15 кратно числу 3.
	(обратно) 3 не кратно числу 15.

Коды возврата

Код	Значение

ST_OK			успех
ST_ERR_ARGC		неверное число аргументов
ST_ERR_FLAG		неизвестный флаг
ST_ERR_PARSE		параметр не число
ST_ERR_RANGE		параметр вне диапазона
ST_ERR_ZERO		нулевой параметр
ST_ERR_NOT_TRIANGLE	не треугольник
ST_ERR_NO_ROOT		нет перестановок
