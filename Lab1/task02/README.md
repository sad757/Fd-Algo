# Задание 2 — Константы e, π, ln 2, √2, γ

## Условие

Реализовать функции, вычисляющие значения чисел **e**, **π**, **ln 2**,
**√2**, **γ** с заданной точностью. Для каждой константы реализовать
**три способа** вычисления:

1. Как сумму ряда;
2. Как решение специального уравнения;
3. Как значение предела.

Точность (значение эпсилон) подаётся программе в качестве аргумента
командной строки.

## Компиляция

	 gcc -std=c99 -Wall -Wextra -Wpedantic -o task2 task2.c -lm

!! Ключ -lm обязателен: используются функции log, exp, pow,
lgamma, log1p.

Использование

	./task2 e 1e-10       # число e
	./task2 pi 1e-6       # число π
	./task2 ln2 1e-10     # ln 2
	./task2 sqrt2 1e-12   # √2
	./task2 gamma 1e-6    # постоянная Эйлера — Маскерони

Формат вывода

e     : ряд=... уравн=... предел=... (эталон=...)
pi    : ряд=... уравн=... предел=... (эталон=...)
ln2   : ряд=... уравн=... предел=... (эталон=...)
sqrt2 : ряд=... уравн=... предел=... (эталон=...)
gamma : ряд=... уравн=... предел=... (эталон=...)

Методы

Константа				Ряд				Уравнение					Предел

e 					Σ 1/n!				ln x = 1					(1 + 1/n)ⁿ
π              				Лейбниц: 4 Σ (-1)ⁿ/(2n+1)	cos x = -1					Формула Валлиса
ln 2					Σ (-1)ⁿ⁻¹/n			eˣ = 2						n · (2^(1/n) - 1)
√2					Биномиальное разложение		x² = 2						Итерация x_{n+1} = x_n - x_n²/2 + 1
γ					Σ [1/k - ln(1 + 1/k)]		Γ'(1) = -γ					H_n - ln n

Замечания

Формула Валлиса даёт медленную сходимость — для eps = 1e-10 может
потребоваться много итераций;

Для γ метод «через уравнение» использует приближение производной
функции Γ через конечную разность;

Все циклы ограничены сверху, чтобы избежать бесконечного выполнения.

Коды возврата

Код	        Значение

ST_OK		успех
ST_ERR_ARGC	неверное число аргументов
ST_ERR_NAME	неизвестное имя константы
ST_ERR_PARSE	ошибка разбора эпсилон
ST_ERR_RANGE	эпсилон вне ]0, 1[
ST_ERR_CONV	сходимость не достигнута
ST_ERR_DIVZERO	деление на ноль
