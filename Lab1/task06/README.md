# Задание 6 — Функции с переменным числом аргументов

## Подзадания

1. **6.1** — вариадическая функция `is_convex`, определяющая, является ли
   многоугольник выпуклым. Координаты вершин передаются через `...`.
2. **6.2** — вариадическая функция `poly_eval`, вычисляющая значение
   многочлена степени n в точке x (схема Горнера). Коэффициенты передаются
   от старшей степени к свободному члену.
3. **6.3** — вариадическая функция `kaprekar_search`, находящая среди
   переданных строк представления чисел Капрекара в заданном основании.
4. **6.4** — вариадическая функция `geo_mean`, вычисляющая среднее
   геометрическое. Количество чисел — последний параметр.
5. **6.5** — рекурсивная функция `pow_fast`, реализующая быстрое возведение
   в степень.
6. **6.6** — функция `dicho`, находящая корень уравнения методом дихотомии.
   Принимает указатель на функцию.

## Компиляция

	gcc -std=c99 -Wall -Wextra -Wpedantic -o task6 task6.c -lm

Использование

	./task6 -convex 4 0 0 1 0 1 1 0 1          # квадрат
	./task6 -poly 3 2 2 -3 4 -5                # 2x³ - 3x² + 4x - 5 при x=2
	./task6 -kap 10 9 45 55 99 297 703         # числа Капрекара в base 10
	./task6 -geo 3 9 27 3                      # среднее геометрическое 3, 9, 27
	./task6 -pow 2 10                          # 2^10
	./task6 -pow 2 -3                          # 2^(-3)
	./task6 -dicho 0 2 1e-10 1                 # корень x²-2 = 0
	./task6 -dicho 0 1 1e-10 2                 # корень cos(x) - x = 0

Замечания

Диспетчер вариадических функций построен на switch по количеству
параметров, так как в C нельзя динамически сформировать va_list
из argv.

Для многочленов и многоугольников поддержаны разумные ограничения
(степень ≤ 5, вершин ≤ 6) — этого достаточно для демонстрации
