# Задание 4 — Обработка файлов

## Условие

На вход программе через аргументы командной строки подаётся флаг и путь
к файлу. Флаг определяет действие с входным файлом.

Если флаг содержит вторым символом `n` (`-nd`, `-ni`, `-ns`, `-na`), то
путь к выходному файлу является **третьим** аргументом командной строки.
Иначе имя выходного файла генерируется приписыванием к имени входного
файла префикса `out_`.

## Флаги

- `-d` — исключить символы арабских цифр из входного файла;
- `-i` — для каждой строки посчитать количество латинских букв;
- `-s` — для каждой строки посчитать символы, отличные от букв, цифр и пробела;
- `-a` — заменить символы, отличные от цифр, их ASCII-кодом в 16-ричной системе.

## Компиляция

	gcc -std=c99 -Wall -Wextra -Wpedantic -o task4 task4.c

Использование

	./task4 -d in.txt              # → out_in.txt
	./task4 -ni in.txt letters.txt # вывод задан явно
	./task4 -a in.txt hexa.txt

Коды возврата

Код			Значение

ST_OK			успех
ST_ERR_ARGC		неверное число аргументов
ST_ERR_FLAG		неверный флаг
ST_ERR_OPEN_IN		не удалось открыть входной файл
ST_ERR_OPEN_OUT		не удалось открыть выходной файл
ST_ERR_READ		ошибка чтения
ST_ERR_WRITE		ошибка записи
ST_ERR_NAME_LONG	слишком длинное имя файла
