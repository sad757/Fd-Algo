# Задание 9 — Массивы

## 9.1 — Фиксированный массив

	./task9 -1 <a> <b>


Заполнить массив фиксированного размера (N = 100) псевдослучайными
числами в диапазоне [a..b], где a, b задаются в качестве аргументов
командной строки.

Реализовать функцию, которая за один проход по массиву находит
максимальное и минимальное значения элементов и меняет их местами
в исходном массиве.

9.2 — Динамические массивы

	./task9 -2

Заполнить динамические массивы A и B псевдослучайного размера
в диапазоне [10..10000] псевдослучайными числами в диапазоне
[-1000..1000]. Сформировать из них динамический массив C, где i-й
элемент массива C есть i-й элемент массива A (A[i]), к которому
добавлено значение ближайшего к A[i] по значению элемента
из массива B.

Если ближайших по значению элементов несколько — допускается добавление
любого из них.

Компиляция

	gcc -std=c99 -Wall -Wextra -Wpedantic -o task9 task9.c

Метод

9.1: один проход по массиву, поддерживая индексы min и max.

9.2: массив B сортируется (qsort), для каждого A[i] бинарным
поиском находится ближайший элемент. Сложность — O((n + m) log m).

Коды возврата

Код		Значение

ST_OK		успех
ST_ERR_ARGC	неверное число аргументов
ST_ERR_FLAG	неверный флаг
ST_ERR_PARSE	параметр не число
ST_ERR_RANGE	параметр вне диапазона
ST_ERR_NOMEM	недостаточно памяти
