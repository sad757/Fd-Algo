# Задание 7 — Продвинутая обработка файлов

## Условие

На вход программе подаётся флаг и пути к файлам.

## Флаг `-r`

	./task7 -r <файл1> <файл2> <выходной>

Записать в выходной файл лексемы из файлов file1 и file2 так, чтобы:

на нечётных позициях находились лексемы из file1;

на чётных — из file2.

Лексемы во входных файлах разделены произвольным количеством пробелов,
табуляций и переводов строк. Если количество лексем в файлах различается,
после достижения конца одного из файлов необходимо переписать в выходной
файл оставшиеся лексемы из другого. Лексемы в выходном файле разделены
одним символом пробела.

Флаг -a

	./task7 -a <входной> <выходной>

Преобразовать каждую лексему входного файла в зависимости от её позиции:

в каждой десятой лексеме сначала все буквы латинского алфавита
преобразуются в строчные, затем все символы преобразуются в
эквивалентные им ASCII-коды в системе счисления с основанием 4;

в каждой второй (и одновременно не десятой) лексеме все буквы
преобразуются в строчные;

в каждой пятой (и одновременно не десятой) лексеме все символы
преобразуются в эквивалентные им ASCII-коды в системе счисления
с основанием 8.

Лексемы в выходном файле разделены одним пробелом.

Компиляция

	gcc -std=c99 -Wall -Wextra -Wpedantic -o task7 task7.c

Примеры

	# -r
	echo "un deux trois quatre" > f1.txt
	echo "A B C D E F" > f2.txt
	./task7 -r f1.txt f2.txt merged.txt
	cat merged.txt

	# → un A deux B trois C quatre D E F

	# -a
	./task7 -a input.txt output.txt

Коды возврата

Код			Значение

ST_OK			успех
ST_ERR_ARGC		неверное число аргументов
ST_ERR_FLAG		неверный флаг
ST_ERR_OPEN_IN		ошибка открытия входа
ST_ERR_OPEN_OUT		ошибка открытия выхода
ST_ERR_READ		ошибка чтения
ST_ERR_WRITE		ошибка записи
ST_ERR_LEX_LONG		лексема слишком длинная
